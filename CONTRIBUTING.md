# Contribute to the OpenHarmony port

For changes to this downstream port, follow [the contributor guide](ohos/CONTRIBUTING.md) and [maintenance workflow](ohos/docs/maintenance.md). File port issues and pull requests in `flypigJ/go-ohos`; this fork does not import pull requests into Go Gerrit.

For a defect reproduced with unmodified official Go, use [the upstream contribution process](https://go.dev/doc/contribute). The original Go contribution document is retained in [CONTRIBUTING.upstream.md](ohos/CONTRIBUTING.upstream.md). Do not send private downstream device data to upstream issues.
